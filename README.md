# TaskYUL — пакет для независимого хостинга

Файлы можно разместить на обычном статическом HTTPS-хостинге. Зависимостей от ChatGPT для запуска нет. Личные начальные задачи и проекты удалены из этого пакета: первое открытие пустое.

В Netlify после регистрации Free: загрузите эту папку через https://app.netlify.com/drop. Не выбирайте платный тариф. Сначала проверьте полученный адрес на iPhone с выключенным VPN. Доступность в конкретной сети заранее не подтверждена.

Установка: Safari → Поделиться → На экран «Домой». Откройте один раз с интернетом, дождитесь «Готово к работе без сети», закройте, включите авиарежим и снова откройте с домашнего экрана.

Это веб-приложение, не TestFlight. Данные хранятся отдельно для каждого устройства и адреса сайта. Старые задачи, заметки и вложения сами не перенесутся. Не удаляйте старый сайт и его данные. Синхронизация и перенос данных ещё не реализованы.

Free-тариф Netlify ограничен месячной квотой: https://www.netlify.com/pricing/
